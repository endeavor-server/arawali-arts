## Quick Architecture Summary

* **500 Master SKUs**: 50 categories across 8 manufacturing divisions (10 SKUs each).
* **Direct Logistics**: Factory-stuffed & customs-sealed at ICD Jodhpur (Thar/Basni), rail transit to Mundra Port, India.
* **Streamlined UI**: Minimalist navbar with 2-panel Categories Explorer and clean Myntra vertical facet filtering.
* **Deployment**: Hosted on Oracle Cloud Infrastructure (`130.210.42.84`), Docker container `arawali-web`.
